# Assignment 3 – Mobile Computing

Question-wise solutions, language-independent pseudocode, configurable CSV inputs and a standard-library Python simulation for Q1–Q7.

## Run
```bash
python "Assignment 3/mobile_computing_assignment3.py"
```
Python 3.9+. No external packages required. Generated CSVs are saved in `outputs/`.

## Contents
- Q1–Q7 answer files
- `pseudocode/`: algorithm specifications using ALGORITHM, INPUT, OUTPUT, BEGIN, IF, FORWARD, DELIVER and RETURN
- `inputs/`: editable scenario datasets
- `outputs/`: generated result CSVs
- `diagrams/`: Mermaid diagrams

**Model limitation:** outputs are deterministic illustrative calculations, not real-world measurements or packet-level network simulation. Mobile IP uses traditional Mobile IPv4 terminology from the supplied brief. Mobile IP mobility management and AODV/DSDV routing solve different problems.
