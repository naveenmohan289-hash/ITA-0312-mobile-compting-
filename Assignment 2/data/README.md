# Assignment 2 input data

This folder contains the declared input assumptions used by the Q1–Q7 simulations.
The main script currently generates repeatable traffic/fading samples from fixed random
seeds; these CSV files document the scenario parameters and decision criteria used
for the experiments. They are editable inputs/reference data, not measured field data.

Run from the repository root:
```bash
pip install -r "Assignment 2/requirements.txt"
python "Assignment 2/implement_q1_q7.py"
```
Generated results are written to `Assignment 2/outputs/`.
