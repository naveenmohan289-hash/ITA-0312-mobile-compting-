# Mobile Computing Assignment 2 — Q1 to Q7

This folder contains question-wise answers, a reproducible Python implementation, shared utilities, input/reference data, and generated output summaries.

## Folder contents
- `Answers_Q1-Q7.md` — answers, assumptions, calculations, analysis and conclusions.
- `implement_q1_q7.py` — runnable simulations for all seven questions.
- `common.py` — shared CSV and directory utilities used by the main program.
- `requirements.txt` — Python package requirements.
- `data/` — traffic scenarios, technique ratings, criteria weights and Q7 parameters.
- `outputs/` — committed result summaries and CSV files generated by the program.

## Setup and run
From the repository root:

```bash
pip install -r "Assignment 2/requirements.txt"
python "Assignment 2/implement_q1_q7.py"
```

Or from inside the `Assignment 2` folder:

```bash
pip install -r requirements.txt
python implement_q1_q7.py
```

The program writes question-numbered CSV results into `outputs/`.

## Notes
- Python 3.9 or later is recommended.
- The models are educational simulations, not vendor-grade physical-layer simulators.
- Randomized experiments use fixed seeds for repeatability.
- Input CSV files document scenario assumptions and reference criteria. Results are simulated, not measurements from a live mobile network.
