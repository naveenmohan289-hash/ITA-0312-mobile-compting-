# Outputs

CSV/JSON result files are generated by running python common.py all from the Assignment 4 directory. The checked-in policy and analysis CSVs are reproducible rule-model outputs. Q2 host timing is generated on the machine where the script is run and is intentionally not committed as a universal benchmark. Device profiler/logcat/Battery Historian evidence must be collected on the target device and saved separately; no physical-device measurements are claimed in this repository.
