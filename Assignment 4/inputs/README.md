# Input datasets

- q2_workload_spec.csv: deterministic workload categories for the threading comparison.
- q3_runtime_test_matrix.csv: compilation-filter predictions and required device evidence.
- q4_security_config.json: security audit fixture consumed by common.py.
- q5_power_conditions.csv: seven power-state conditions consumed by task5.
- q6_tracking_scenarios.csv: seven tracking policy scenarios consumed by task6.

Edit copies of these files to add tests. Preserve the original rows so results remain reproducible.
