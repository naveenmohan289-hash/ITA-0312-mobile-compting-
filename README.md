# Assignment 1 – Cellular Frequency Planning

This folder contains question-wise answers (Q1–Q12), a reproducible Python planning
simulator, test output, CSV measurements and plots.

## Run
```bash
python -m pip install -r requirements.txt
python src/planner.py --self-test
python src/planner.py --out results
```

## Folder structure
- `Assignment_Answers.md` – answers to all 12 tasks.
- `src/planner.py` – simulator and mathematical helper functions.
- `results/` – CSV, JSON and PNG outputs generated by the simulator, including fixed channel plan, dynamic allocation demo and splitting recurrence.
- `run_log.txt` – captured execution output.
- `requirements.txt` – Python dependencies.

## Important modelling assumptions
The assignment brief does not specify a channel count, per-subscriber traffic,
cell radius, propagation constants, or a measured traffic map. To make the work
reproducible, the model declares: 420 total full-rate channel equivalents,
R = 0.5 km, 0.02 Erlang/subscriber, 12 km² service area, 2% target blocking,
and random seed 197226. These are planning assumptions, not measured facts.
The Monte-Carlo SIR model uses a first-tier approximation. The sectorized case
retains two dominant interferers. Dynamic assignment is represented by a
12% pooled-trunking gain approximation. Replace these assumptions with field
measurements before deployment.
