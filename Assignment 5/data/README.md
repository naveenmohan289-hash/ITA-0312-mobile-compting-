# Input data
- b1_sensor_jobs.json: job priority, sensitivity, encryption, criticality, minimum battery and metered-network policy.
- b2_workloads.json: two equal-size six-record workloads with easy/adversarial structure.
- b3_feed_cases.json: three small UI/feed cases, including a low-battery counterexample candidate.
- b4_device_profiles.json: entry, mid-range, flagship and low-battery sample device/network profiles.
All values are authored teaching inputs, not real patient or field-device data.
